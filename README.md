1. 과제를 통해 알게 된 것

1-1) placement new  
일반적인 new는 메모리 할당과 객체 생성을 해주는 역할을 하지만 placement new는 조금 달랐습니다. 프로그래머가 미리 할당해놓은 메모리 공간을 재사용하는 기능으로 메모리 할당은 하지 않고 객체 생성만 하는 것이 특징입니다. 예시 코드는 아래와 같습니다.
~~~ c++
char buffer[100];           // 메모리 공간 확보
Test* p = new (buffer) Test(); // 그 공간에 객체 생성
~~~

1-2) reference  
c언어에서 포인터만 보다가 레퍼런스를 처음 알았는데 비교군이 생겨서 덕분에 포인터에 대한 개념이 좀 더 잘 잡힌 계기가 되었습니다. 포인터는 특정 데이터의 위치주소를 저장하는 변수입니다. 변수이므로 얼마든지 다른 위치주소를 넣을 수 있습니다. 레퍼런스도 이와 비슷하게 특정 데이터의 위치주소를 가리키는 역할을 하지만 한번 가리킨 대상을 변경할 수 없다는 점에서 상수에 가깝습니다. 일종의 "별명" 역할을 하는 것인데 그래서 레퍼런스는 생성과 동시에 반드시 초기화가 되어야 한다는 점이 중요합니다. 별명은 본체가 있어야 그 존재가 성립되기 때문입니다. 간략한 예제 코드는 아래와 같습니다.
~~~ c++
   int num = 10;
   
   // 포인터
   int* ptr = &num;
   *ptr = 20;
   
   // 레퍼런스 
   int& ref = num; //레퍼런스 생성과 동시에 초기화
   ref = 30;
~~~

1-3) reference와 initializer list  
앞서 설명했듯 reference는 생성과 동시에 초기화가 되어야 합니다. 그래서 클래스에서 멤버 reference를 만들 때는 반드시 initializer list에서 초기화되어야 할 필요가 있습니다. 클래스가 생성되고 난 후 생성자를 통해 값을 초기화하는 것은 이미 늦기 때문입니다.

~~~ c++
class MyClass {
    int& ref; // 참조자 멤버

    // 잘못된 방법
    MyClass() {
        ref = someValue; // 생성자에서의 초기화는 생성된 후 이뤄지기 때문에 X
    }

    // 올바른 방법
    MyClass(int& value) : ref(value) { // 이니셜라이저 리스트를 사용한 초기화
    }
};

~~~
